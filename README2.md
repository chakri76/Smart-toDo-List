# 📝 Smart To-Do List Application

A simple, interactive, and user-friendly To-Do List application built using **HTML5, CSS3, and JavaScript**. This application helps users manage daily tasks efficiently with automatic data storage.

## 🚀 Features

- **Create Tasks:** Add new tasks easily.
- **Read Tasks:** Display all added tasks.
- **Update Tasks:** Edit existing tasks.
- **Delete Tasks:** Remove unwanted tasks.
- **Mark Completed:** Mark tasks as completed using checkboxes.
- **Task Filtering:** Filter tasks into All, Active, and Completed categories.
- **Local Storage:** Automatically saves tasks in the browser.
- **Data Persistence:** Tasks remain saved even after refreshing the page.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
- Browser Local Storage

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Smart-Todo-List.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Start adding and managing your tasks!

## 💡 How It Works

1. Enter a task in the input field.
2. Click the Add Task button.
3. Edit or delete tasks whenever required.
4. Mark tasks as completed.
5. Use filters to view specific tasks.
6. Your tasks are automatically saved using Local Storage.
